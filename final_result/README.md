# Final result: Model A vs Model B, g2 autocorrelation for every flow condition

Generated by `scripts/plot_final_result.py`.

## Final setting
- **Data:** K = 5 trials per condition whose measured outlet flow is closest to the pump preset
  (`dataset/testset_closest_k5.csv`), 132 conditions ((0,0) excluded), 660 trials.
  Real curve = mean g2 of the 5 trials (black, solid).
- **Model A** (blue, dashed): paper-geometry MCX (100 x 50 mm, layers 5.5 / 35 mm), 1e8 photons,
  5,000 photons per SDS; alpha*D_B = a * max(FR_meas, 0) + D_B0 with
  a = 9.425e-8 mm^2/s per ml/min/100g and D_B0 = 6.675e-7 mm^2/s, fitted on the 660 trials
  (Nelder-Mead, least squares of g2). Per-trial curves from each trial's measured flow, averaged
  over the 5 trials.
- **Model B** (orange, dotted): Wichuda_r commit 64985e7 with the photon pathlength unit fixed
  (voxel -> mm, x0.5): alpha*D_B = 0.4e-6 * preset flow, no baseline, beta per condition.

## Files
- `conditions/cond_<shallow>_<deep>.png`: one figure per condition, SDS 1 / 2 / 3 cm side by side
- `all_conditions.pdf`: the same 132 figures, one per page
- `grid_SDS1cm.png`, `grid_SDS2cm.png`, `grid_SDS3cm.png`: all 132 conditions as small multiples
- `metrics_per_condition.csv`: R^2 (1 - SS_res/SS_tot) and RMSE of A and B against the condition-mean real curve
- `settings.json`: fitted constants and input files
